# Karakeep

Karakeep provides a searchable bookmark overview and shortcuts to saved links, including their title, URL, icon, and collection.

## Files

- `integration.yaml` contains the Karakeep API request, bookmark response mapping, computed display fields, and widget or shortcut configuration.
- `karakeep.md` documents the integration for contributors and users.

## Configuration

- `URL` — required base URL of the Karakeep instance.
- `TOKEN` — optional Karakeep bearer token.

Bookmarks are sorted by title and link back to the corresponding Karakeep URL.
